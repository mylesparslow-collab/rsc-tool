Setting up Claude on your Mac

Reclaimed Space Crafters

Claude is an AI helper. Once it is set up, you can type a request in plain English, like "the phone number on the website is wrong" or "the Expenses page shows the wrong total", and Claude makes the fix on your computer. It asks you before it changes anything. Do this setup once, ideally with Myles on the phone.

Set it up (once)

  1. Have a paid Claude account Claude needs a Pro or Max plan for this. Myles will tell you which account and email to use.
  2. Download the Claude app In Safari or Chrome go to claude.com/download and press the Mac download. Open the file that downloads, then drag the Claude icon into the Applications folder.
  3. Open Claude and sign in Open Claude from Applications (or the Launchpad). Sign in with the email Myles gave you. You can drag the icon to your Dock so it is easy to find.
  4. Put the website on your Mac In the email from Myles, double-click rsc-website.zip. A folder called rsc-website appears. Drag it into your Documents folder.
  5. Know where the RSC app lives The RSC app's folder is called rsc-tool. It is wherever you unzipped it when you installed the app (often your home folder or Downloads). Leave it where it is. Moving it breaks the app.

Two kinds of access

KindWhat Claude can do
Folder access
(what you'll use)		Read and change files only inside the one folder you pick: rsc-tool or rsc-website. It can't see your email, photos or other files.
Computer use
(off; not needed)		Sees your screen and clicks in other apps. It asks before using each app. Leave it off unless Myles says otherwise (see page 3).

Asking Claude for a fix

Same steps for the app and the website
  1. Open Claude and press the Code tab (top of the window, next to Chat and Cowork)
  2. Pick where it works Below the message box, make sure it says Local (your Mac). Then pick the folder: rsc-tool to fix the RSC app, or rsc-website (in Documents) to change the website. Claude only touches that folder.
  3. Set it to ask first Next to the send button, set the mode to Manual. Claude then asks before every change, and you can say yes or no.
  4. Say what you want, in plain words Start with this line, then describe the problem: Read CLAUDE.md first, back up, and explain each step to me simply. Here's the problem: Then, for example: "The weekly report says $0 collected but Hartwell paid last week." or "On the website, change the hours to Monday to Friday, 7 to 4."
  5. Approve or say no Claude shows what it wants to do and waits. Press Allow (or Accept) if it makes sense. Press Deny (or Reject) if you're not sure, and ask it to explain. Press Esc to stop it any time.
  6. Finish the job For the RSC app, end with: Run the tests, run rsc doctor, restart the app, and tell me what you changed and where the backup is. For the website, ask Claude to "open the page so I can look." When you like it, text Myles. Myles puts website changes online; changes on your Mac don't show on the live site until he does.

Good things to ask for

  • Fix a wrong word, number or button
  • "Why does this page look wrong?"
  • "Make this page easier to read"
  • Add a step to an estimate template
  • Website: phone, hours, text, a new photo
  • Website: answer a "What to confirm" item
  • "The app won't open. What's wrong?"
  • "Undo what you just did."

Ask Myles first before changing contract wording (a lawyer still needs to review it), your 43% markup, or anything that would send email or connect to QuickBooks.

Staying safe

Keep this list by the computer

Six rules

  1. Back up first Every request starts with "back up" (the line on page 2 does it). If something goes wrong, the backup puts it back.
  2. Never share a password Don't type or paste your Gmail app password, bank logins or QuickBooks login into Claude. The RSC app keeps the Gmail one locked in the Mac's Keychain; it never needs it again.
  3. Nothing goes out without you Don't let Claude send email to clients or crew for you. Emails should open in Mail so you read them and press Send yourself.
  4. Read before you press Allow If you don't understand what it wants to do, press Deny and ask, "Explain that in plain words."
  5. Delete only with a reason If Claude asks to delete a file, say no unless Myles told you to expect it.
  6. When in doubt, stop Press Esc, take a picture of the screen, and text it to Myles.

Turning things off

  • Stop Claude right now: press Esc or the stop button. Closing the Claude window also stops it.
  • Folder access: each conversation works in only the one folder you picked for it. To be done, close the conversation; nothing else on your Mac was opened.
  • Computer use (screen control) is off unless someone turns it on in Claude › Settings › General › Enable computer use. To take it away, turn that switch off. If it is ever on, Claude asks before using each app: don't allow Mail, your bank or QuickBooks.

If you're stuck

Ask Claude, "What's going on? Explain it simply." If that doesn't help, quit Claude, take a picture of the screen and text Myles. Your jobs and money records are safe in the RSC folder in your home folder, with a backup made every day.
